🎯 Python Number Guessing Game

A simple command-line number guessing game built using Python.

The program randomly generates a number between 1 and 100, and the player tries to guess it. The game provides hints if the guess is too high or too low and tracks the number of attempts.

---

🚀 Features

- Random number generation
- Hints for high or low guesses
- Attempt counter
- Score system based on attempts
- Exception handling for invalid input

---

🛠 Technologies Used

- Python 3
- Random module
- Exception Handling
